# Negocios con NFC: investigación y Kit NFC para anfitriones

| Carpeta o archivo | Qué es |
|---|---|
| `guia-negocios-nfc.md` / `.pdf` | Investigación: 28 ideas de negocio con chips NFC, puntuaciones y recomendación |
| `kit-anfitriones/web/` | Web del Kit NFC para pisos turísticos en España: portada, pedidos, guía del huésped, panel del anfitrión y panel de vendedor (HTML + JS + Supabase) |
| `kit-anfitriones/guia/` | Guía de ejecución día a día (90 días) en Markdown y PDF, con capturas |
| `kit-anfitriones/plantillas/` | Diseño del azulejo (SVG) y hoja de pegatinas de 30 mm |

Para probar la web, abre `kit-anfitriones/web/index.html`: funciona en modo demo sin configurar nada. Para lanzarla, lee `kit-anfitriones/web/README.md`.
